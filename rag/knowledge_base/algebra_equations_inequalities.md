# Algebra: Equations & Inequalities

## Systems of Linear Equations
- Substitution method: solve one equation for a variable, substitute into the other
- Elimination method: add/subtract equations to eliminate a variable
- Cramer's Rule: x = det(A_x)/det(A), y = det(A_y)/det(A)

## Inequality Rules
- Multiplying/dividing both sides by a negative number FLIPS the inequality sign
- For |x| < a: -a < x < a
- For |x| > a: x < -a or x > a

## Quadratic Inequalities
To solve ax^2 + bx + c > 0:
1. Find roots r1, r2 (r1 < r2)
2. If a > 0: solution is x < r1 or x > r2
3. If a < 0: solution is r1 < x < r2
Always check if discriminant is negative (no real roots).

## AM-GM Inequality
For non-negative real numbers:
(a1 + a2 + ... + an)/n >= (a1 * a2 * ... * an)^(1/n)
Equality holds when a1 = a2 = ... = an

## Cauchy-Schwarz Inequality
(a1*b1 + a2*b2 + ... + an*bn)^2 <= (a1^2 + ... + an^2)(b1^2 + ... + bn^2)

## Common JEE Tricks
- Substitution: Let t = x + 1/x for symmetric expressions
- For sum of series: use telescoping or partial fractions
- Wavy curve method for polynomial inequalities
