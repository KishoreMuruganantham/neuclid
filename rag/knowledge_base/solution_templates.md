# Solution Templates

## Template: Solving Quadratic Equations
1. Write equation in standard form: ax^2 + bx + c = 0
2. Identify a, b, c
3. Calculate discriminant: D = b^2 - 4ac
4. If D >= 0: x = (-b +/- sqrt(D)) / (2a)
5. If D < 0: roots are complex: x = (-b +/- i*sqrt(|D|)) / (2a)
6. Verify by substituting roots back

## Template: Evaluating Limits
1. Try direct substitution first
2. If indeterminate (0/0): try factoring, rationalizing, or standard limits
3. If still 0/0 or inf/inf: apply L'Hopital's Rule
4. For 1^inf form: use e^(lim g(x)*(f(x)-1))
5. For 0*inf: rewrite as 0/0 or inf/inf
6. Verify with numerical approximation if possible

## Template: Optimization Problems
1. Draw a diagram (if geometric)
2. Assign variables to unknowns
3. Write the objective function (what to maximize/minimize)
4. Write the constraint equation
5. Use constraint to eliminate one variable from objective
6. Differentiate and set equal to zero
7. Check second derivative or endpoints
8. State the optimal values

## Template: Probability Problems
1. Define the sample space clearly
2. Identify the event of interest
3. Choose method: classical, conditional, or complement
4. If sequential: use multiplication rule with tree diagram
5. If "at least": use complement method
6. Calculate and simplify
7. Verify: probability must be between 0 and 1

## Template: Matrix/Determinant Problems
1. Write the matrix clearly
2. For determinant: expand along row/column with most zeros
3. For inverse: check det != 0 first, then use adjoint method or row reduction
4. For systems: form augmented matrix, apply row operations
5. Check rank conditions for existence/uniqueness of solutions

## Template: Derivative Application (Tangent/Normal)
1. Find f'(x) using appropriate differentiation rules
2. Evaluate f'(a) at the point of interest
3. Tangent line: y - f(a) = f'(a)(x - a)
4. Normal line: y - f(a) = -1/f'(a) * (x - a)
5. Verify the point lies on the curve
